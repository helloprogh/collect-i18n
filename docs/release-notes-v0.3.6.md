# Collect I18n v0.3.6

此版本把采集流程从“逐 key 交互”升级为“按路由批量检查点捕获”，并新增一个 1000 词条的真实复杂度示例工程用于性能验证。

## 改进

- 路由级批量采集：`agent next` 返回 `routeBatch`，把同一路由下未解决的词条聚合成一个批次；Agent 按“初始状态 + 高扇出状态切换”建立带 `capture` 检查点的路由覆盖计划，一次执行可捕获数十个可见词条。
- 新增 TriggerPlan `capture` 步骤：在每个状态切换前记录当前所有可见的 A/B 级未解决词条，替代原先的逐 key `waitForKey` 轮询，显著减少浏览器往返。
- 批量可见性捕获：引擎通过单次页面求值批量定位可见目标，配合单次进入状态与稳定等待，再逐目标截图，降低重排与等待开销。
- 新增 `examples/oms-complex-app`：真实无 mock 的 OMS 复杂界面，包含变量 key 传递、Element Plus 消息弹框、表格、表单与校验提示等 1000 词条场景，作为采集性能与准确率的验证基准。

## 修复

- 移除逐 key 1000ms 等待轮询导致的采集串行化瓶颈。

## 测试

- 新增批量捕获调度相关用例；全量 123 项测试与类型检查通过。
