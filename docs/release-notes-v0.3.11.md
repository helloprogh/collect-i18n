# Collect I18n v0.3.11

修复 Excel 导出中截图丢失原始宽高比的问题：上一版使用固定 `twoCell` 锚点把 1440×900 的证据截图拉伸进固定行高的小格子，画面严重变形。

## 修复

- **截图按原始宽高比等比缩放（关键）**：导出工作簿时解析每张截图自身的 PNG/JPEG 尺寸，改用 `oneCell` 锚点 + 显式像素尺寸（`xdr:ext`）写入。`ext.width` 与截图列宽（约 207px）对齐，`ext.height` 由 `源图高 / 源图宽` 按每张图独立计算，行高随图片高度自适应。不再把不同比例的截图压进同一固定格子。
- **新增 PNG/JPEG 尺寸解析**：PNG 读取 IHDR 的宽高（大端）；JPEG 扫描 SOF 段读取宽高，两者都保持零依赖。
- **锚点语义简化**：图片改为跟随单一单元格（`editAs="oneCell"`），避免两单元格跨行拉伸导致的显示漂移；排序后仍与对应 Key Path 行严格对齐。

## 验证

- 全量 138 项测试、类型检查、构建、Skill 打包通过（新增单测断言 `editAs="oneCell"`、`ext` 宽高比与源图一致、行高与图片高度匹配）。
- 使用真实采集会话（session_4865e7d5…）重新导出 1000 词条工作簿：765 张内嵌截图的 `ext` 宽高比与源 PNG（1440×900）全部一致，无一张变形。
- 打包产物 `collect-i18n-skill-v0.3.11.zip` 内 CLI `--version` 输出 `0.3.11`。

## 影响

- 导出的 Excel 中每行截图都保持自身原始比例，横竖屏截图均可正确显示；列宽/行高自适应，不依赖查看器字号。
